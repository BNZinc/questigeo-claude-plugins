# 1.0.4: Hosted Browser MCP

## Changes

- Bundle `questi-geo-browser` through the public HTTPS MCP endpoint. The
  connection uses Questi OAuth, with no credentials or local executable in the
  package.
- Prefer the hosted browser over native computer-use tools. Do not silently
  switch execution environments when authentication or tool discovery fails.
- Finish drawing requests with real PNG and editable GGB download links.
  Device-local paths are only valid after actual local download verification.
- Document session limits, expiring bearer links, blocked private/paid actions,
  and the hosted mode's unavailable GGB re-import verification.
- Validate the endpoint and component configuration during both source sync and
  release checks. Package only the committed, allowlisted distribution files.
